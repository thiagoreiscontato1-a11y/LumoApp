# Lumo iOS — abrir no Xcode

1. Baixe o ZIP da branch `feature/ios-prototype-0.1.0` pelo GitHub (Code > Download ZIP).
2. Descompacte e abra `Lumo.xcodeproj` na raiz do repositório.
3. Selecione o target Lumo > Signing & Capabilities > seu Personal Team.
4. Conecte o iPhone, selecione-o no Xcode e pressione Run.

Este projeto referencia os arquivos Swift em `ios/`. É um protótipo inicial não compilado nem testado no Xcode. Se houver erro de compilação, envie a mensagem do Xcode. Ainda não possui conexão Canon, presets Lightroom ou Fotto.
