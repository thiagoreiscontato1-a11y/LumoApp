# Lumo iOS 0.1.0 — protótipo inicial

Este é um protótipo SwiftUI para testar no iPhone: criação de eventos, importação via Fotos, galeria simples, edição básica da primeira imagem e compartilhamento/exportação JPEG.

## Abrir no Xcode
1. Instale o Xcode e abra **File > New > Project > iOS > App**.
2. Nome: **Lumo**; Interface: **SwiftUI**; Language: **Swift**.
3. Substitua o arquivo App gerado pelo conteúdo de `LumoApp.swift` e a tela inicial pelo conteúdo de `ContentView.swift`. Não deixe dois arquivos com `@main`.
4. Escolha seu iPhone no topo do Xcode, configure seu Personal Team em Signing & Capabilities e pressione Run.

**Importante:** ainda não é um projeto `.xcodeproj` pronto para abrir. Não foi compilado nem testado no Xcode. A importação e as edições são locais; não há tethering Canon, presets XMP, Fotto ou persistência de fotos importadas nesta etapa.
